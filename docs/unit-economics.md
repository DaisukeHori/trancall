## 結論

1. **Whisper併用時はStandard/Businessが大幅赤字**。input transcriptを優先し、Whisperは品質不足時のfallbackとする

## 日本MSCA（2025/12/18施行）対応シナリオ

### MSCAによる選択肢

2025年12月18日に施行されたMobile Software Competition Act (MSCA)により、日本市場では以下の選択肢が利用可能。**MSCAでは「IAP併設必須」(side-by-side model)** — 代替決済を提供する場合もIAPを同じ画面に同時表示する必要がある。

| 方式 | 実効Apple手数料 | 内訳 | 条件 |
|------|----------------|------|------|
| IAP標準 | 30% | 通常コミッション | 海外市場のデフォルト |
| IAP + SBP | 15% / 10% | SBP割引 | 年間100万USD未満、サブスク2年目以降10% |
| IAP MSCA適用 | 21% | 日本ストア向け | デジタル商品 |
| IAP MSCA + SBP | 10% | SBP割引適用 | 上記+SBP適用 |
| **StoreKit External Purchase (SBP対象外)** | **20%程度** | Store Services Fee 13% + Initial Acquisition Fee 2%(初回6ヶ月のみ) + CTC 5% | リンクタップから7日以内の取引、IAP併設必須、Apple月次レポート提出義務 |
| **StoreKit External Purchase + SBP** | **15%程度** | Store Services Fee 10% + Initial Acquisition Fee 0%(SBP) + CTC 5% | SBP適用 |
| Webサブスク（アプリ外） | 0%（Stripe 3.6%のみ） | App Store規定外 | アプリ内に決済導線なし、"manage"リンクのみ |

注: StoreKit External Purchase は Store Services Tier 2 (App Store の全機能利用可) 前提。Tier 1 (5%) は App Store discovery/分析/featured 等を失うため通常非推奨。

### 推奨戦略（購入チャネル多角化）

TranCallでは購入チャネルの多角化を方針として採用する。ユーザーは状況に応じて最適なチャネルを選択できる。

1. **Phase 1c は3チャネルすべてを併設**:
   - (a) **IAP（MSCA 21%/SBP適用時10%）** — App Store審査で最も安全、サブスク管理がApple経由でユーザーに分かりやすい
   - (b) **StoreKit External Purchase（実効15-20%）** — アプリ内に「Webで購入」ボタンを置き、Stripe決済ページへ誘導。IAPと同じ画面で併設する（MSCAルール）
   - (c) **Webサブスク（Stripe 3.6%）** — アプリ外で完結、B2B法人契約や年間プランで利用

2. **チャネル選択のヒント表示**:
   - アプリ内: 「Appleで購入(簡単・Apple経由で管理)」と「Webで購入(お得・自分で管理)」の2ボタン併設
   - アプリ外サイト: B2B/法人向けに「年間契約・請求書払い対応」を明示

3. **SBP適用条件**(年間売上100万ドル以下)を維持する間は10-15%レンジで運用可能

4. **海外市場(Phase 2以降)**: MSCA非適用なので IAP 30% (SBP適用なら15%) 一本 + 価格を市場ごとに調整

### 購入チャネル選択フロー

```
日本市場？
├── Yes → 3チャネル併設
│   ├── アプリ内: IAP + StoreKit External (Stripe link) を同画面で併設 (MSCA準拠)
│   │   ├── SBP適用可能？
│   │   │   ├── Yes → IAP 10% / StoreKit External 実効15%
│   │   │   └── No → IAP 21% / StoreKit External 実効20%
│   │   └── ユーザーが選択（UIで両方を平等に提示）
│   └── アプリ外Web: Stripe直接(3.6%) — B2B、法人契約、年間プラン
└── No (海外) → IAP一本 (30% / SBP適用時15%)
```

### 運用上の注意

- **StoreKit External Purchase APIの実装が必須**: Apple disclosure sheet表示、外部購入トークンの発行、Apple月次レポート提出
- **Apple月次請求対応**: StoreKit External Purchase の手数料はAppleから請求書が来るので、経理処理を運用設計に組み込む
- **VATの取り扱い**: 日本MSCAでは VAT 込みでコミッション計算されるが、開発者側で消費税の納税義務は別途発生
- **Phase 1c 直前に最新の Apple Japan ガイドラインを再確認**: 2025年12月施行から日が浅く、運用ルールが変更されている可能性あり
